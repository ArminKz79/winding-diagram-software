# ⚡ طراحی و ترسیم دیاگرام سیم‌پیچی الکتروموتور

### 📝 معرفی برنامه

این برنامه ابزاری کاربردی برای **محاسبات، طراحی و ترسیم نقشه گسترده سیم‌پیچی استاتور الکتروموتورهای جریان متناوب (AC)** است که با هدف ساده‌سازی فرآیند طراحی سیم‌پیچی و نمایش دقیق نحوه قرارگیری و اتصال کلاف‌ها توسعه داده شده است.

با استفاده از این ابزار می‌توان بر اساس مشخصات الکتروموتور، از جمله تعداد شیارهای استاتور، تعداد قطب‌ها، نوع موتور و آرایش سیم‌پیچی، نقشه گسترده سیم‌پیچی را طراحی و به‌صورت گرافیکی مشاهده کرد.

برنامه با پشتیبانی از موتورهای تک‌فاز، سه‌فاز و دو‌فاز، امکان طراحی آرایش‌های مختلف سیم‌پیچی را فراهم می‌کند. همچنین با نمایش مجزای کلاف‌های هر فاز، محاسبات مربوط به گروه‌بندی و سربندی کلاف‌ها و مشخص کردن خروجی‌های سیم‌پیچ، فرآیند بررسی و اجرای نقشه را ساده‌تر می‌کند.

هدف اصلی این برنامه، فراهم کردن ابزاری دقیق و کاربردی برای مهندسان برق، دانشجویان و متخصصان حوزه تعمیرات و سیم‌پیچی الکتروموتور است.

---

### 🚀 قابلیت‌ها و امکانات برنامه

**⚙️ طراحی و محاسبات سیم‌پیچی**
- انجام محاسبات و طراحی نقشه گسترده سیم‌پیچی استاتور الکتروموتورهای AC
- پشتیبانی از طراحی با هر تعداد شیار استاتور
- امکان انتخاب سرعت‌های مختلف موتور متناسب با تعداد قطب‌ها در فرکانس ۵۰ هرتز (۳۰۰۰، ۱۵۰۰، ۱۰۰۰ دور و ...)
- پشتیبانی از موتورهای تک‌فاز، سه‌فاز و دو‌فاز

**🔧 آرایش و گروه‌بندی کلاف‌ها**
- پشتیبانی از سیم‌پیچی یک‌طبقه و دو‌طبقه
- امکان طراحی با گام کامل و گام کوتاه
- قابلیت انتخاب نسبت تعداد کلاف‌های اصلی به کمکی (بیشتر، مساوی و کمتر)
- پشتیبانی از گروه‌بندی تکی و جفتی کلاف‌ها
- امکان تنظیم دستی پارامترهای طراحی

**🔌 اتصالات و سربندی**
- امکان اتصال و سربندی کلاف‌ها به‌صورت سری
- قابلیت نام‌گذاری خروجی‌های سیم‌پیچ اصلی (U) و کمکی (Z)
- نمایش مسیر اتصالات و نحوه ارتباط گروه‌های کلاف
- امکان حذف هارمونیک‌های ایجادشده در سیم‌پیچی موتورهای سه‌فاز

**📊 نمایش گرافیکی و دیاگرام**
- ترسیم خودکار نقشه گسترده سیم‌پیچی بر اساس پارامترهای انتخاب‌شده
- نمایش شماره شیارها و موقعیت قرارگیری کلاف‌ها
- نمایش کلاف‌های هر فاز با رنگ متفاوت
- امکان تغییر رنگ کلاف‌ها
- قابلیت نمایش یا مخفی کردن سیم‌پیچ‌های اصلی و کمکی به‌صورت مجزا
- نمایش اطلاعات محاسباتی شامل تعداد شیار، قطب، کلاف، گروه و گام کلاف‌ها

### 💡 مزایای استفاده از برنامه

- **افزایش سرعت طراحی:** کاهش زمان موردنیاز برای محاسبات و ترسیم دستی نقشه سیم‌پیچی
- **کاهش خطای انسانی:** کمک به کاهش اشتباهات در محاسبات، گروه‌بندی و اتصالات کلاف‌ها
- **نمایش دقیق اتصالات:** مشاهده مسیر سیم‌پیچ‌ها و نحوه سربندی گروه‌های کلاف
- **انعطاف‌پذیری بالا:** امکان طراحی سیم‌پیچی با آرایش‌ها و مشخصات مختلف
- **درک بهتر ساختار سیم‌پیچی:** تفکیک رنگی فازها و نمایش گرافیکی نقشه گسترده
- **کاربرد آموزشی و صنعتی:** مناسب برای یادگیری، آموزش، طراحی و استفاده در تعمیرگاه‌های سیم‌پیچی الکتروموتور
